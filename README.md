# Hyena Quest Cheat

Delivery & Beyond（游戏内叫 *Hyena Quest*）的联机作弊插件。BepInEx 5 插件，纯本地客户端改的，给同房间一起玩的人省事用的。

## 安装

游戏自带 BepInEx，下下来就能用：

1. 把整个 `BepInEx` 文件夹直接拖进游戏目录覆盖合并，或者只把 `HyenaQuestCheat.dll` 放进：

   ```
   <游戏目录>\BepInEx\plugins\
   ```

   也就是 `steamapps\common\Delivery-Beyond\BepInEx\plugins\`。

2. 启动游戏，按 `Insert` 呼出面板（进游戏默认开着）。

## 功能

- **解放双手** — 自动接单送货，全程自己跑
- **一键配送** — 自动拨号 + 拿货 + 送达，循环干活；别的玩家靠近电话会被轻轻弹开
- **秒杀 / 操控** — 杀全部、推飞、全员血 1、抢货到脚下、丢包、碎玻璃、一键满袋（房主）
- **一键吸废料** — 全图吸，满袋自动回收回船上（房主）
- **无敌 / 移动加速 / AA**（AA 下视角不晃）
- **公屏刷屏**

键位：`Insert` 开关面板，`F5` 开关吸废料，别的都从面板点。

## 说明

- **界面比较简陋**，能用就行，懒得美化。
- **不开源**，只发编译好的 DLL。
- 服务端权威的数值（金币、废料存量）改不动，这插件全走"客户端说了算"的空子。
