BepInEx 5 插件。游戏自带 BepInEx，把编译出的 `HyenaQuestCheat.dll` 扔进
`<游戏目录>\BepInEx\plugins\`，重启游戏，按 **INS** 出面板（默认开启）。

源码已开源，随便拿去改，二创随意。

## 功能方面

能用的全在这，按用途分：

- **自动挂机**：跑房杀（自动跳房：进房→杀全部→退出→下一间，无限循环，可扫公开房）、一键解放双手（自动通关，需房主）、一键配送（拨号 + 拿货 + 送达循环）、一键吸取废料（全图吸，可直接吸满）、满袋自动回收船上（房主）
- **保命**：无敌（血量永远 ≥1）、移动加速（1~10x 平滑渐变）、反观战（房主对外假死 / 房客观战黑屏）、防整·锁物反抢（拦攻击 RPC + 抢回被偷物）
- **恶心别人**：秒杀 / 补刀（破 D-SAFE）、推飞 / 连推、控血（钉 1 血 / 满血 / 循环）、抢物到脚下、丢包、碎玻璃、拉人（房主）、复活、自杀（仅手动）、瞄准快捷键（镜头对准：杀 / 复活 / 1血 / 推飞 / 抢物 / 丢包）
- **整活**：旋转 AA（转圈 / 偏移 / 低头）、飞行 / 穿墙、公屏刷屏
- **视觉**：ESP 透视（3D 方框 + 血 / 废料 / 手持物品）
- **面板**：INS 开关、热键可自定义（键盘 / 鼠标）、可拖拽缩放

## 可能存在的 Bug

实话实说，我没法把每个功能在每台机器、每种对局下都测一遍，bug 肯定有。
自己已知的：

- **AA 那块有毛病**，具体啥毛病懒得细查，也懒得修，能用就凑合用
- **一键解放双手**是流水线，哪一步断了（网络、地图没刷出来）可能卡住，有超时兜底，但不敢保证百分百顺
- **飞行 / 穿墙**跟物理系统有交互，快速穿地形偶尔会被弹回原地
- **跑房杀**跳房频率高，连续跑有触发 Steam 风控的风险；扫的是公开房，碰到的玩家不可控

其它的——你用了遇到再说，遇到了可以加群喊我。
