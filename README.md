# Hyena Quest Cheat（Delivery & Beyond 辅助）

BepInEx 5 插件。游戏自带 BepInEx，把编译出的 `HyenaQuestCheat.dll` 扔进
`<游戏目录>\BepInEx\plugins\`，重启游戏，按 **INS** 出面板（默认开启）。

源码已开源，随便拿去改，二创随意。

## 功能（实话实说，全列了）

### 自动
| 功能 | 说明 |
|---|---|
| 一键解放双手 | 自动通关：吸废料 → 入账船上 → 拨号 → 送货 → 还清债务。**需房主**。 |
| 无敌 | 血量永远 ≥ 1 |
| 一键吸取废料 | 全图吸，可直接吸满（房主瞬间 / 客户端 ~1s） |
| 满袋自动回收船上 | 房主：袋满自动入账船上继续吸 |
| 一键配送 | 拨号 + 拿取 + 送达循环，全程弹开接近电话的玩家 |
| 旋转 AA | 转圈 / 静态偏移 / 低头，本地视角不受影响 |
| 移动加速 | 1~10x 平滑渐变 |
| 飞行 / 穿墙 | WASD + 空格上 / Ctrl 下；穿墙自动带飞行控制（**本次新增**） |
| 公屏刷屏 | 单发 / 连发，自定义消息和间隔 |

### 操控（全是远程 Everyone RPC，点按钮就生效）
| 功能 | 说明 |
|---|---|
| 秒杀 / 补刀 | 破 D-SAFE 保命道具 |
| 推飞 / 连推 | 一直推上天，站不起来 |
| 控血 | 钉 1 血 / 满血 / 循环 |
| 抢物到脚下 | 目标手里拿的 + 背包里的全抢过来 |
| 丢包 | 强制目标清空背包 |
| 一键满袋 | 房主秒满真空袋 |
| 碎全场玻璃 | 全场远程 |
| 复活 | 自己 / 单目标 / 全员，零成本，客户端也能用 |
| 拉人 | 房主：把玩家拉到自己身边 |
| 自杀 | 仅手动，任何自动功能不会触发 |

### 其它
- 热键可自定义（键盘 / 鼠标按钮），改完写进 cfg，下次启动保持
- 面板可拖拽、右下角缩放

## 实话实说
- **不是所有功能都 100% 测试到位，bug 肯定有**。修不修纯看我想不想玩，小游戏不值得投入太多精力。
- **界面是 Unity 现成 IMGUI 随手写的，很简陋**，能点能用就行，纯懒不美化。
- 服务端权威字段（金币、废料总量）改不动，上面这些走的是「客户端权威 + 服务端不校验」的空子。
- AA 部分有已知的小毛病，不影响其它功能，暂时不修。

## 二创
源码在 `src/`，Visual Studio 直接打开 **`HyenaQuestCheat.sln`** 就能改。
构建需要装好游戏（csproj 引用了游戏目录里的程序集），跑 `build.bat` 或 VS 里 F5 都行。
改完随便自己用、自己发，随意。
